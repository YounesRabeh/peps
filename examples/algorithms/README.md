# Peps Algorithms

These complete programs demonstrate familiar algorithms using Peps language
features. Run any file from the project root with `cargo run -- <file>`.

| File | Algorithm | Demonstrates |
| --- | --- | --- |
| `01-factorial.peps` | Factorial | recursion and multiplication |
| `02-fibonacci.peps` | Fibonacci sequence | branching and recursive calls |
| `03-greatest-common-divisor.peps` | Euclidean GCD by subtraction | loops, conditionals, reassignment |
| `04-linear-search.peps` | Linear search | list indexing and recursive traversal |
| `05-binary-search.peps` | Binary search | divide-and-conquer recursion and list access |

All `.peps` files in this directory are executed by the Rust example-program
test suite.
