# 3. Conditionals

An `if` starts with `🤔`, followed by a boolean expression and a block between
`🔓` and `🔒`. Use `😐` for an optional else branch.

```peps
🐶 🟰 4️⃣
🟢 🟰 💬large💬
🔴 🟰 💬small💬
🤔 🐶 ▶️ 3️⃣ 🔓
    📢 🟢
🔒 😐 🔓
    📢 🔴
🔒
```

Conditions must evaluate to `✅` or `❌`. Blocks create a new lexical scope;
the scope rules are covered in guide 6. Run the
